Rules learned while checking the Asset Profile screens on staging

  1. Asset Profile has six screens: Asset Serial Global List, Generate Barcode, Asset In Pending Process List, Asset Serial Split, Asset Serial Split List and Asset Serial Split Approval List.
  2. Open an asset by clicking its Asset Serial in the Global List. The popup has seven tabs and four Change buttons.
  3. Source Of Fund: choose a fund, then Update. Update does nothing until a fund is selected.
  4. Asset Utilization Status: choose a status (SPLIT, IN_USE, DAMAGE, STOLEN, BURNED, DONATED, OFFLINE_TRANSFER, UNDER_REPAIR) and write a Note saying why. The Note is required, so every change can be tracked.
  5. Item: type the new Item Specification, IMEI or serial number, then Update.
  6. Measurement: Change unlocks the box; type or correct the value and click Update. The unit follows the item (Land uses Decimal, most items Pcs). The value can also be typed when the asset is registered.
  7. An asset can only be split when its Measurement is above zero. Otherwise the screen says: Cannot split: Please set a valid measurement above zero.
  8. Generate Barcode: search the asset, tick its row, set the print quantity (1 to 99; Set copies one quantity to the ticked rows) and click Generate. The barcode PDF opens in a new browser tab.
  9. Asset In Pending Process List shows assets in any unfinished process and the screen each one is pending in. An asset with a pending transaction cannot be picked on Asset Assign, Un Assign, Internal Movement or Asset Expense until it is approved. Export saves the list as Excel.

Rules learned while checking the Asset Expense screen on staging

  1. Add the asset to the grid first: enter the Expense Amount and click Add, and only then choose the Expense Source. Otherwise the Credit A/C list stays empty.
  2. Vendor/Supplier/Lessor Name is required for both sources. Without it the message is: Vendor/Supplier/Lessor Name is required.
  3. Inventory: Category, Sub Category and Item Name are required and match the asset (for a Cabinet Table: Furniture, Wooden Furniture, Cabinet Table). Credit A/C fills in as Other Inventory [1107010401-02].
  4. Accounts: Category, Sub Category and Item Name are disabled. Credit A/C fills in as Supplier Payable-Opex[2101010301-05].
  5. Debit A/C: Other Maintenance Expenses[5108010101-07], chosen by hand for both sources.
  6. Expense Ref. is required (any text; the tests use EXP plus six random digits). The Expense ID is generated as soon as the expense is saved, whether you click Draft or Submit (BBDEXP00000001, ...); store it, it is the key to find the expense again.
  7. To check the automatic journal after approval: Accounting > Voucher > Voucher Search, same date in Date From and Date To, Transaction Number = the Expense ID, Search, then Preview (the voucher opens as a PDF in a new tab). Inventory: Other Maintenance Expenses Dr. / Other Inventory Cr.; Accounts: Other Maintenance Expenses Dr. / Supplier Payable-Opex Cr.

Particulars -
Purchase PriceThe purchase price of the asset. If the asset is split, a new serial number is generated and the purchase price is adjusted accordingly.
Total AdditionThe Total Addition column is normally blank. If there is a depreciation mismatch, the backend adjusts it by adding or subtracting the required value.
Total Unit PriceThe total unit price of the asset.
Accumulated Dep.The total accumulated depreciation of the asset.
Written Down ValueThe written down value of the asset.
